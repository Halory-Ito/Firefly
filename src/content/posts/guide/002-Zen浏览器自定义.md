虽然也是自己一步一步从AI嘴里问出来的，但是好歹烧了token，也花了时间

**Prerequisites**

1. 启用自定义配置：首先访问`about:config`，将`toolkit.legacyUserProfileCustomizations.stylesheets`设置为`true`
2. 开启CSS调试：将`devtools.chrome.enabled`设置为`true`
3. 创建自定义文件：访问`about:support`，找到“打开配置文件夹的按钮”，新建`chrome`文件夹，并在其中创建`userChrome.css`和`userContent.css`文件

浏览器自定义（非内容区）需要在`userChrome.css`中进行配置，目前只做了如下：

```css
/* 修改所有标签页（包括非激活状态）的圆角 */
.tabbrowser-tab .tab-background {
  border-radius: 12px !important;
}

/* 为几乎所有元素设置字体，但排除标题栏按钮 */
*:not(.titlebar-buttonbox-container *) {
  font-family: "Noto Serif SC", sans-serif !important;
}

#navigator-toolbox {
  --zen-compact-float: 0px !important;
  border: none !important;
  background-color: var(--zen-main-browser-background-toolbar) !important;
}
```

如果要修改内容区的样式，比如`about:*`、`https://*`等需要通过地址栏访问的网站，就需要在`userContent.css`中进行修改，不过其实一般只需要对浏览器内置的页面进行修改就可以了，而且主要是字体方面

```css
/* 针对 about:* 页面设置字体 */
@-moz-document url-prefix("about:") {
  * {
    font-family: "Noto Serif SC", sans-serif !important;
  }
}
```
